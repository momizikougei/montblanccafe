# 菓子喫茶 モンブラン Webサイト

ビルド不要の静的サイトです。フォルダごとサーバーに置けば公開できます。

```
index.html      ページ本体（文章はここ）
favicon.svg     ブラウザのタブに出るアイコン
css/style.css   レイアウト
css/theme.css   色・質感・装飾（色は先頭の :root で管理）
js/data.js      お店の情報・メニュー・価格・写真のURL
js/main.js      オーニングの描画・本日の営業表示などの処理
```

## よくある更新

| 変えたいもの | 場所 |
|---|---|
| 営業時間・定休日 | `js/data.js` の `hours` / `bands` / `hoursText` |
| メニュー・価格 | `js/data.js` の `menu`（`price: null` は「—」と表示） |
| 写真 | `js/data.js` の `PHOTOS`（`images/` に置いた画像のパスを書く） |
| 住所・Instagram | `js/data.js` の先頭 |
| 文章 | `index.html` |
| 色 | `css/theme.css` の `:root` |

## 公開前に必要なこと

- **写真の差し替え**：いま入っている写真は、社内レビュー用に食べログの投稿写真を仮で読み込んだものです。公開前に、お店で撮影・許諾を得た写真へ必ず差し替えてください。
  特に「大分の店」「家族・店主」の2枚は、内容の合う写真がないため別の写真を仮置きしています。
- **価格の入力**：メニューの価格はすべて未入力です。
- **お持ち帰り商品の確認**：TAKE OUT の品目は仮です。
- **営業時間の確認**：公開媒体によって定休日の表記に差があります。公式Instagramで最新の情報を確認してください。
- 「本日の営業」は曜日と時刻から自動で表示します。祝日は判定していません。

## 確認方法

`index.html` をブラウザで直接開いても表示されます。地図の埋め込みなどを本番に近い状態で確かめたい場合は、ローカルサーバーで開いてください。

```bash
python3 -m http.server 8000
```

開いたあと、ブラウザで http://localhost:8000 にアクセスします。
